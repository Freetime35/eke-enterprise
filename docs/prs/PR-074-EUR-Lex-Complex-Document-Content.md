# PR-074 — EUR-Lex Complex Document Content

Adds:

- structured table cells with row and column spans;
- table captions and source ordering;
- formula preservation through MathML, text or image URI;
- footnotes with markers and source-node references;
- visual resource metadata without OCR;
- a dedicated XML/XHTML complex-content parser;
- application and infrastructure tests;
- ADR-0069.

No persistence migration or public HTTP endpoint change is required.
