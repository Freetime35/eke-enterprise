# PR-066 — EUR-Lex English Titles Enrichment

Adds:

- typed title roles: official, short, alternative and unknown;
- deterministic RDF predicate mapping;
- English-only title projection;
- whitespace normalization and typed deduplication;
- backward-compatible title construction;
- application and infrastructure tests;
- ADR-0061.

No migration or public HTTP endpoint change is required.
