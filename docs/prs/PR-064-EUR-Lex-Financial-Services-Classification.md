# PR-064 — EUR-Lex Financial Services Classification

Adds:

- canonical English financial topic categories;
- deterministic selection of banking and financial EuroVoc concepts;
- preservation of source scheme, broader and narrower concept URIs;
- exclusion of non-English and non-financial concepts;
- canonical mapping of selected concepts only;
- application and infrastructure tests;
- ADR-0059.

No migration or public HTTP endpoint change is required.
