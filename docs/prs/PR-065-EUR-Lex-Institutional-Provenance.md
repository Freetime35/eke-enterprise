# PR-065 — EUR-Lex Institutional Provenance

Adds:

- normalized English institution records;
- deterministic URI mapping for EU institutions and financial bodies;
- canonical derived provenance for ECB, EBA, ESMA, EIOPA and SRB;
- preservation of unknown institutional URIs;
- RDF/XML institution extraction and deduplication;
- application and infrastructure tests;
- ADR-0060.

No migration or public HTTP endpoint change is required.
