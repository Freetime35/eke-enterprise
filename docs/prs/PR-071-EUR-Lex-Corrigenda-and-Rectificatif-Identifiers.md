# PR-071 — EUR-Lex Corrigenda & Rectificatif Identifiers

Adds:

- dedicated corrigendum identifiers such as `32013L0036R(01)`;
- canonical base-act and sequence representation;
- source-backed corrigendum metadata;
- optional publication dates;
- deterministic deduplication and ordering;
- `EurLexMetadata` and RDF/XML parser integration;
- application and infrastructure tests;
- ADR-0066.

No migration or public HTTP endpoint change is required.
