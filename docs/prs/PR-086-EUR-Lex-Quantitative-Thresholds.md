# PR-086 — EUR-Lex Quantitative Thresholds

## Summary

Introduces immutable quantitative-threshold models and a deterministic extractor.

## Supported

- explicit comparators
- numeric ranges
- currencies
- percentages
- count, mass, length, area, volume, energy and time units
- deterministic identifiers
- qualifier provenance
- duplicate elimination

## Deliberate limitations

No unit conversion, currency conversion, formula evaluation, inferred thresholds
or probabilistic interpretation.
