# PR-069 — EUR-Lex Legal References and Citations

Adds:

- canonical legal-reference kinds;
- explicit CELEX and URI targets;
- optional source-backed article labels;
- separation from strong legal relationships;
- deterministic deduplication;
- metadata and RDF/XML parser integration;
- application and infrastructure tests;
- ADR-0064.

No migration or public HTTP endpoint change is required.
