# PR-070 — EUR-Lex Consolidated Acts and Version Lineage

Adds:

- initial-act, consolidated, codified, recast and corrigendum lineage kinds;
- explicit version and base-act CELEX identifiers;
- optional source-backed consolidation dates;
- deterministic deduplication and chronological ordering;
- metadata and RDF/XML parser integration;
- application and infrastructure tests;
- ADR-0065.

No migration or public HTTP endpoint change is required.
