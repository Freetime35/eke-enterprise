# PR-009.1 — GitHub Actions Continuous Integration

## Objective

Add automated quality validation for every push and pull request.

## Added

- `.github/workflows/ci.yml`
- Python 3.11 environment provisioning
- Editable installation with development dependencies
- Automated Pytest execution
- Automated Ruff execution
- Automated Mypy execution
- Pip dependency caching
- Read-only repository permissions
- Cancellation of superseded workflow runs

## Workflow triggers

The workflow runs on:

- every push;
- every pull request.

## Quality commands

```bash
python -m pytest
python -m ruff check .
python -m mypy
```

## Design notes

The workflow intentionally uses one Python version and one operating
system during the current pre-alpha phase.

A Python version matrix may be introduced when the supported version
policy expands.

## Recommended commit

