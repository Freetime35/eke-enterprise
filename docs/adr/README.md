# Architecture Decision Records

This directory contains the Architecture Decision Records (ADRs) for
EKE Enterprise.

ADRs document significant architectural decisions, their context,
alternatives, consequences, and status.

## Naming convention

ADR files use the following format:

```text
ADR-0001-short-decision-title.md
```

## Status values

Each ADR must use one of these statuses:

- Proposed
- Accepted
- Superseded
- Deprecated
- Rejected

## Required sections

Each ADR should contain:

1. Title
2. Status
3. Context
4. Decision
5. Consequences
6. Alternatives considered
7. References
